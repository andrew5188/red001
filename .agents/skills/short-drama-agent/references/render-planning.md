# 按清晰度与本地显卡配置默认渲染方案

## 先确定需求，再自主配置

先补齐目标清晰度和画幅；不要强迫用户填写采样器等技术参数。横屏16:9的720p对应最终1280×720，竖屏9:16对应720×1280；其他画幅明确具体像素尺寸。记录原始要求、最终交付尺寸与模型内部尺寸，区分三者。

硬件与节点检测为只读：使用实际ComfyUI地址的system_stats/object_info，必要时结合nvidia-smi、模型目录和节点源码。记录GPU型号、总/可用显存、系统内存、现有模型精度、加速LoRA、SelfLift节点版本和H3 latent放大权重。多GPU时明确执行卡，不擅自视为显存可相加。不能仅凭“3060”假设一定是12GB。

默认技术路线固定为SelfLift渐进采样＋H3 latent放大，根据清晰度、单组时长、参考图数量和检测结果自主生成具体配置，不再例行要求用户选择路线。配置说明包括：

- 生成基础尺寸→内部放大/精修尺寸→精确最终交付尺寸。
- H3模型及加速LoRA、普通或SelfLift采样、H3 latent放大所在环节、是否需要第二次采样。
- 画质/速度取舍、显存管理策略、依赖已具备或缺失、试片范围。
- 时间或显存数字注明“本机实测”或“估计”；无依据时写待试片测量，不编造分钟数或加速倍数。

目标清晰度已明确且用户已授权制作时，说明具体配置后即可构建工作流与运行必要试片；不再等待技术路线选择。一般参数调整自主进行。实际需要放弃默认组合、降低交付要求或增加未授权依赖/成本时，给出具体理由与替代方案供用户决定。

## 固定默认组合与可查询的新工作流

默认链路：H3参考条件与音视频latent→SelfLift低分辨率前段采样→H3 latent upscaler提升→目标分辨率后段采样→音视频解码与封装。提升器接在SelfLift内部的过渡环节即可，不要求额外独立放大节点或重复放大。确有目标尺寸需求时才增加后续提升/精修，记录额外成本。

自主构建的是经本机验证后复用的主模板，不是每场景或每10秒重新搭建节点。初始化时依据当前schema构建；后续优先绑定参数并复用，只有节点结构或生成方式改变时才调整模板。先查本机object_info、已装版本和源码；遇到兼容性未知、缺失能力、生成失败或新要求时，可查询官方文档与原作者仓库/示例，核对后按当前环境重建API图和UI图。保存信息来源、相关版本、实际节点与参数。线上最新参数不能直接假设本机已支持，不为重建工作流自动更新插件或下载大型模型。

默认组合不可行时才讨论替代路线，例如普通采样后H3 latent放大或原生目标尺寸生成；替代路线不是可静默采用的默认项。去掉SelfLift、去掉H3 latent提升器或更换模型架构，应明确说明并取得用户选择。

SelfLift与H3 latent放大不是互斥项。SelfLift是渐进采样方法，不是替换H3的独立视频模型；H3 latent upscaler是latent空间提升器，不等同于SelfLift-rich训练模型。

根据当前安装实现核对参数。2026-09-19本机facok SelfLift仅接受标准Euler，不能使用不兼容的采样器。H3适配属于实验性，论文图像模型指标不能冒充本机H3结果。当前实现区分H3外部提升器且rho=0的latent-only路径，与upscaler_model=none且rho>0的SelfLift-zero路径；不要混称。参数需按已装版本核对，transition_step必须留出实际高分辨率采样步骤，不能照抄图像模型的默认6步到四步总采样。

## RTX 3060 / 720p只是条件示例

确认是RTX 3060 12GB且目标确为横屏720p时，优先配置温和的SelfLift＋H3 latent提升组合，不宣称必定更快或必定不溢出。10秒音视频、参考数量、编码器与主模型驻留都会影响内存。沿用本机已验证的量化模型和兼容加速LoRA，单组执行，按实际支持采用卸载、解码分块或分段处理。

内部尺寸遵守当前模型/节点对齐要求。若不能直接使用1280×720，选择保持接近画幅的合法尺寸，并在方案里说明最终等比缩放及必要的少量裁切或补边；不得把1280×736直接叫作精确720p，也不把插值缩放称为细节恢复。2倍upscaler须核实实际倍率与支持尺寸，不能随意填任意倍数。

高分辨率采样分块不默认开启；当前H3 SelfLift分块会改变空间注意力与音频处理，和VAE解码分块不是同一件事。以本机版本行为和试片结果决定，不把省显存写成无损保证。

## 构建、试片与保存

需求明确且制作已授权后，在项目根目录iworkflow/构建项目专用API图与可编辑UI图。执行前读取用户已保存的修改并同步API；保存版本与提交快照，不覆盖用户编辑。不自行更新插件或下载大型模型来凑齐方案；缺少依赖时说明具体影响和解决方式。

选择包含脸、手、细小动作和对白的代表性组验证该方案。需要加速对照时，明确实验范围，固定相同素材、种子、时长、目标尺寸和兼容采样参数；记录加载/编码、采样、提升、解码及端到端耗时。只运行有助于选择或验证的对照，避免无限调参。检查身份、手部、纹理闪烁、口型、台词和音轨；未能试听的内容标为未验证。

project.json保存：settings.rendering.target_resolution、target_width/height、hardware_snapshot、default_route、configured_plan、selection_source、selection_status、workflow_strategy、workflow_paths、research_sources、benchmark_results。default_route为selflift_h3_latent_upscale，selection_source为user_skill_default，明确是用户指定的技能默认路线，不伪称用户逐项确认参数。清晰度缺失时selection_status为awaiting_requirements，完成配置后为configured；仅真正需要用户决定替代路线时使用awaiting_selection。旧项目保留明确选定的路线和已完成产物，新增要求仅影响待制作配置。
