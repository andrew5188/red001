# 《借你一场雪·问剑》续篇大纲 v1（待用户确认）

本稿仅供故事确认，尚未加入project.json的制作场次，不生成新角色、场景或视频。原有50秒雪亭故事继续完成。以下为新增20场（S02—S21），每场后续可拆成多个10秒视频，不将20场直接等同于20段。

## 已确认关系与新增人物

- 用户已确认：女主的师弟暗恋女主，看到她与谢临川亲近后生出嫉妒，提出比武。
- 沈知微：沿用18岁成年女主；温柔但有主见，明确表达自己的选择。
- 谢临川：沿用约30岁成年男主；认真对待对手，克制而有分寸。
- 陆行舟（暂定名）：18岁成年师弟，入门较晚，和知微相处已久。习惯在她身边，因此把熟悉误当作必然的亲近。剑术有长处，嫉妒让他急于证明自己；不是单纯作恶的反派。

主线：师弟试图借比武证明自己值得被选择，最终面对“胜负不能替别人决定感情”。知微主动划清边界；临川既回应她的感情，也尊重师弟的尊严。整体由甜蜜转为酸涩、紧张，再回到温暖，保留仙侠与雪景气氛。

| 场次 | 地点与情节 | 主情绪／人物变化 | 类型与动作方向 |
|---|---|---|---|
| S02 雪廊撞见 | 延续原片末尾。陆行舟从回廊走来，看到知微与临川站在一起，脚步停住，原本要喊出的称呼咽回去。 | 师弟：期待→失落；两人仍处于原片的安心。 | 文戏，动作LoRA关。 |

| S04 三人的茶席 | 三人在亭中坐下。临川自然替知微挡住吹来的风，她看向他的笑容让行舟意识到两人的亲密。 | 师弟：嫉妒升起；男女主：日常温柔。 | 文戏，避免三人同步微笑。 |
| S05 一句逞强 | 行舟谈起自己的剑术进境，话里带出与临川比较的意思。临川认真听，并没有轻视他，反而让他更难发作。 | 师弟：急于证明自己；男主：平和尊重。 | 文戏，不把挑衅写成恶语羞辱。 |
| S06 师姐的回答 | 知微在竹廊追上行舟。他问“你是不是更相信他？”她察觉不对，告诉他相信与喜欢不能拿来排名。 | 女主：关心→认真；师弟：受挫却仍不肯承认暗恋。 | 文戏，情绪靠对视与回避表达。 |
| S07 递出战帖 | 行舟在石阶前拦下临川，以同门礼数提出切磋。表面求教，握紧剑鞘的手暴露紧张与竞争心。 | 师弟：不甘→下定决心；男主：察觉真实动机。 | 文戏；挑战不等于已经开始打斗。 |
| S08 她不是赌注 | 知微听见比武请求，主动说明：可以切磋，但不能把她的感情作为输赢条件。她的选择由自己表达。 | 女主：温柔而坚定；师弟：被看穿后的难堪。 | 文戏，保留女主主动性。 |
| S09 定下三合 | 临川接受三次交锋、点到即止的规则，也请行舟把他当真正的对手，而非争夺感情的障碍。行舟答应。 | 男主：尊重与认真；师弟：从逞强转为备战。 | 文戏，明确不伤人、不赌感情。 |
| S10 雪夜磨剑 | 行舟独坐灯下，擦拭剑身，想起与师姐共度的平常日子。他把未送出的剑穗放在一旁，承认自己害怕失去位置。 | 师弟：嫉妒底下的孤独与不安。 | 文戏，无需突然增加新回忆角色。 |
| S11 清晨入场 | 次日练剑坪。知微布好护场阵，三人确认规则。她不站在奖赏的位置，而是主动维护切磋的边界。 | 三人：肃静、克制，紧张升起。 | 文戏；持剑准备，不启用大幅动作增强。 |
| S12 第一合：试锋 | 行舟先出一记清楚的直线试探，临川侧移格挡。行舟紧接变线，逼退临川半步，展示真实实力。 | 师弟：紧张→获得信心；男主：认真认可。 | 武戏。首场先做10秒动作试片，人工确认后继续。 |
| S13 他想被谁看见 | 暂停间，行舟下意识寻找知微的目光。她为他稳住第一合而点头；他将这份认可误读成还有争取的机会。 | 师弟：短暂得意；女主：对同门进步的欣慰。 | 文戏，视线对象必须明确。 |
| S14 第二合：破招 | 行舟攻势更急，临川以清楚的架剑、转身和卸力化解，让对方失去进攻角度，但没有借机重击。 | 师弟：信心→焦躁；男主：克制、不轻慢。 | 武戏，重点为攻防方向、接触和重心转移。 |
| S15 停一口气 | 知微提醒行舟呼吸乱了。他觉得自己又被当成需要照顾的师弟，情绪失控边缘被触动。临川给他时间重新站稳。 | 师弟：羞恼；女主：担心；男主：留有分寸。 | 文戏，保留比武中真实的停顿。 |
| S16 第三合：逞强 | 行舟试图以尚未掌握稳当的剑诀结束比武，出招后失去平衡，剑气偏离交锋方向。知微自行稳住护场阵，没有成为被动等待救援的人。 | 师弟：急切→惊慌；女主：果断。 | 武戏，主要动作聚焦行舟失衡和偏转，不堆多人连招。 |
